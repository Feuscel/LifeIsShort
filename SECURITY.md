# Security policy

## Supported versions

Security fixes are intended for the latest published version of LifeIsShort. There is not yet a public release channel or canonical repository. Once the project is published, this policy should be updated with supported release details.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Once private vulnerability reporting is enabled for the repository, use GitHub's **Report a vulnerability** feature. If it is not available, contact a project maintainer privately using the contact details on the project hosting profile.

Include the affected version or commit, Android version, steps to reproduce, and potential impact. Do not include private messages, credentials, or other people's personal information. Maintainers will acknowledge reports as soon as reasonably possible and coordinate disclosure after a fix is available.
